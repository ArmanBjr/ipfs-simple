Overview

The FastAPI gateway is a thin layer that forwards upload/download requests to the C engine over a Unix domain socket at /tmp/cengine.sock. Files are chunked and hashed inside the engine; the gateway only streams bytes and renders HTML.

Authentication

Users are stored locally in users.json. When you sign in, the gateway derives an engine token (owner-<sha256(username:password)>) and sends it with every engine connection using opcode 0x05 (AUTH). Owner files written by the engine under owners/ are matched with this token to list your files.

Upload Flow

The browser posts your file to the gateway, which opens a Unix socket and performs:

  1. Send AUTH with your token
  2. Send UPLOAD_START containing total size + filename
  3. Stream chunks with UPLOAD_CHUNK
  4. Signal completion with UPLOAD_FINISH
  5. Wait for UPLOAD_DONE carrying the resulting CID

Download Flow

For downloads the gateway sends DOWNLOAD_START with the CID, relays each DOWNLOAD_CHUNK back to the browser, and finishes on DOWNLOAD_DONE. Filenames are resolved from the manifest in manifests/<cid>.json when present.
